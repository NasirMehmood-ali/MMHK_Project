# MMHK_Project
Python implementation of Hatsugai-Kohmoto model with momentum mixing, reproducing selected results from Mai et al. (arXiv:2401.08746). This work is indented for research training and further exploration of strongly correlated lattice models.
# Historical Background of Hatsugai-Kohomoto(HK) model
This model first proposed by two Japanese researcher, Hatsugai and Kohmoto in 1992. Simple HK model is diagonal in momentum space and readily can be solve.  
# Momentum-Mixing Hatsugai–Kohmoto (MMHK) Model

## Overview

This repository contains Python implementations for numerical calculations related to the momentum-mixing Hatsugai–Kohmoto (MMHK) model. The project focuses on reproducing selected results from the published literature and exploring the model's spectral, charge, spin, and thermodynamic properties.

## Scientific Reference

The primary reference for this project is:

Mai, P., Zhao, J., Tenkila, G., Hackner, N. A., Kush, D., Pan, D., & Phillips, P. W. (2026). "Twisting the Hubbard model into the momentum-mixing Hatsugai–Kohmoto model." *Nature Physics*, **22**, 81–87.

https://doi.org/10.1038/s41567-025-03095-1

The associated source data and scripts are available at:

https://doi.org/10.5281/zenodo.17096693

## Project Scope

The Python scripts implement selected calculations involving the MMHK model, including density of states, spectral properties, charge susceptibility, spin correlations, and thermodynamic quantities.

The objective is to compare independently calculated numerical results with the corresponding results reported in the original paper.
